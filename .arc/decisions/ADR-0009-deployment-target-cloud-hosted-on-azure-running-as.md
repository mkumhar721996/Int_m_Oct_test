## Context

Human's decision: use the organization's approved Azure region (no specific region named beyond that policy).

## Decision

Cloud-hosted on Azure, running as containers (Azure App Service / AKS), deployed in the organization's approved Azure region; relational database run as Azure SQL (managed) in that same region.
